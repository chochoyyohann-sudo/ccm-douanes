✍️ Orthographe — Règles essentielles
16 questions au concours · 30% de l'épreuve
1️⃣
Participe passé avec AVOIR
▼
R1
COD placé AVANT → accord
Si le complément d'objet direct (COD) est placé avant le verbe, le participe passé s'accorde avec lui en genre et en nombre.
✓ Les lettres qu'il a écrites. (COD "que" = lettres, féminin pluriel, placé avant)
✓ Je les ai vus. (COD "les" = masculin pluriel, placé avant)
R2
COD placé APRÈS → invariable
Si le COD est placé après le verbe (ou s'il n'y a pas de COD), le participe reste invariable.
✓ Elle a lavé les mains. (COD après)
✓ Elle a couru. (pas de COD)
R3
Verbes pronominaux — cas particulier
Pour les verbes pronominaux avec avoir, le participe s'accorde avec le COD si celui-ci est placé avant. Locutions figées : "se rendre compte", "se faire" → toujours invariables.
✓ Elle s'est lavé les mains. ("les mains" COD après → invariable)
✓ Elles se sont lavées. (le "se" est COD avant → accord)
✓ Nous nous sommes rendu compte. (locution figée)
2️⃣
Participe passé avec ÊTRE
▼
R1
Accord systématique avec le sujet
Avec l'auxiliaire être, le participe passé s'accorde toujours avec le sujet du verbe.
✓ Elles sont parties. · Il est arrivé. · Nous sommes rentrés.
R2
Verbes toujours avec ÊTRE
Aller, venir, partir, arriver, naître, mourir, rester, tomber, monter*, descendre*, sortir*, entrer*, passer* — et tous les verbes pronominaux.
* peuvent aussi prendre avoir avec un COD
3️⃣
Le subjonctif — quand l'utiliser
▼
R1
Conjonctions imposant le subjonctif
Bien que · Quoique · Pour que · Afin que · Avant que · À moins que · Pourvu que · Bien que · À condition que
✓ Bien qu'il soit fatigué... · Pour qu'elle vienne...
R2
Verbes imposant le subjonctif
Vouloir que · Falloir que · Douter que · Craindre que · Être content que · Souhaiter que · Permettre que
✓ Il faut qu'il parte. · Je veux qu'elle sache.
4️⃣
Homophones classiques du concours
▼
H1
C'est / S'est / Ces / Ses
C'est = ce + est (présentatif) · S'est = pronom réfléchi + est · Ces = démonstratif pluriel · Ses = possessif pluriel
✓ C'est lui. · Il s'est levé. · Ces documents. · Ses affaires.
H2
Quoi que / Quoique · Quel que / Quelque
Quoi que (2 mots) = quelle que soit la chose que · Quoique (1 mot) = bien que
Quel que (2 mots) + verbe être · Quelque (1 mot) + nom
✓ Quoi qu'il fasse... · Quoiqu'il soit fatigué...
✓ Quelle que soit ta décision... · Quelques jours plus tard...
H3
Censé / Sensé · Davantage / D'avantage
Censé = supposé (il est censé venir) · Sensé = raisonnable
Davantage = plus (adverbe) · D'avantage(s) = de bénéfices
5️⃣
Pluriels difficiles & noms composés
▼
P1
Noms composés — règle générale
Seuls les noms et adjectifs prennent la marque du pluriel. Les verbes, prépositions et adverbes restent invariables.
✓ des choux-fleurs · des portes-monnaie · des garde-robes · des haut-parleurs · des gratte-ciel
P2
Pluriels irréguliers à connaître
œil → yeux · bal → bals · carnaval → carnavals · festival → festivals · idéal → idéaux ou idéals
P3
Nombres écrits en lettres
Vingt et cent prennent un "s" uniquement quand ils terminent le nombre et ne sont pas suivis d'un autre chiffre.
Mille est toujours invariable.
✓ quatre-vingts euros · quatre-vingt-deux · deux cents · deux cent cinquante · trois mille
6️⃣
Accords délicats
▼
A1
Tout — adjectif ou adverbe ?
Adjectif (s'accorde) : toutes les femmes · tous les hommes
Adverbe (invariable devant adjectif féminin commençant par consonne) : elle est toute surprise
Adverbe (invariable devant adjectif féminin commençant par voyelle) : elle est tout émue
A2
Demi — invariable avant le nom
Demi- avant un nom : toujours invariable avec trait d'union.
Après un nom : s'accorde en genre seulement (pas en nombre).
✓ des demi-journées · une heure et demie · deux heures et demie
A3
Ni l'un ni l'autre / L'un et l'autre
"Ni l'un ni l'autre" → singulier (le plus courant) : n'est venu
"L'un et l'autre" → pluriel possible : sont venus

▼

▼
Moyenne = Somme des valeurs ÷ Nombre de valeurs
Médiane = valeur centrale (série triée dans l'ordre)
Mode = valeur la plus fréquente
Étendue = valeur max − valeur min

Trouver la médiane
Trier d'abord les valeurs. Si n impair → terme du milieu. Si n pair → moyenne des 2 termes du milieu.

🔢
Suites logiques — types à reconnaître
▼
S1
Suite arithmétique (+n constant)
Calculer les différences entre termes consécutifs.
3, 7, 11, 15... → différence +4 → suivant = 19
S2
Suite géométrique (×n constant)
Calculer le rapport entre termes consécutifs.
2, 6, 18, 54... → rapport ×3 → suivant = 162
S3
Suite à différences croissantes
Les écarts entre termes augmentent régulièrement.
1, 2, 4, 7, 11, 16... → écarts +1,+2,+3,+4,+5 → suivant = 22
S4
Suite de Fibonacci
Chaque terme = somme des deux précédents.
1, 1, 2, 3, 5, 8, 13, 21... → suivant = 34
S5
Suites alphabétiques
Repérer le saut en positions dans l'alphabet. A=1, B=2... Z=26.
A, C, E, G... → +2 → suivant = I
Z, X, V, T... → −2 → suivant = R
🤔
Logique formelle — Syllogismes
▼
L1
Modus ponens (affirmer)
Si P alors Q. P est vrai. → Q est vrai.
Tous les chats sont des mammifères. Rex est un chat. → Rex est un mammifère. ✓
L2
Modus tollens (nier)
Si P alors Q. Q est faux. → P est faux.
Tous les chiens aboient. Rex n'aboie pas. → Rex n'est pas un chien. ✓
L3
Erreur classique à éviter
Affirmer le conséquent = FAUX.
Si P alors Q. Q est vrai. → On NE PEUT PAS conclure que P est vrai.
Tous les chiens aboient. Rex aboie. → On NE PEUT PAS dire que Rex est un chien. ✗
L4
Négation des quantificateurs
Négation de "TOUS les A sont B" = "Il existe AU MOINS UN A qui n'est pas B"
Négation de "AUCUN A n'est B" = "Il existe AU MOINS UN A qui est B"

⚠️ Pièges & Erreurs courantes au Concours C
Les erreurs les plus fréquentes observées dans les annales
✍️ Orthographe
🪤
Participe passé : "il a fallut", "il a fallu"
Le participe passé de "falloir" est "fallu" sans T. Très fréquent dans les annales.
✗ Il a fallut deux heures.
✓ Il a fallu deux heures.
🪤
Pallier à / Pallier — fausse préposition
"Pallier" est un verbe transitif DIRECT. Il ne prend pas de préposition "à".
✗ Pallier à un manque.
✓ Pallier un manque.
🪤
S'avérer faux — pléonasme apparent
"S'avérer" ne signifie pas "se révéler vrai" mais "se révéler". L'expression "s'avérer faux" est donc correcte, pas un pléonasme.
✓ Il s'est avéré que c'était faux. (correct)
🪤
Si + conditionnel — construction interdite
Dans une proposition conditionnelle introduite par "si", on n'utilise JAMAIS le conditionnel.
✗ Si j'aurais su, je serais venu.
✓ Si j'avais su, je serais venu.
🪤
Tout de suite / De suite — confusion fréquente
"Tout de suite" = immédiatement. "De suite" = consécutivement, l'un après l'autre.
✗ Venez de suite ! (sauf contexte de suite consécutive)
✓ Venez tout de suite ! (immédiatement)
🪤
Au jour d'aujourd'hui — pléonasme
"Aujourd'hui" signifie déjà "au jour de ce jour". "Au jour d'aujourd'hui" est un pléonasme à éviter.
✗ Au jour d'aujourd'hui.
✓ Aujourd'hui. / À ce jour.
🔢 Calcul
🪤
Retour au prix initial après remise — erreur classique
Après une remise de 20%, le prix n'est PAS au prix initial en rajoutant 20%. Il faut diviser par (1 - 0,20).
✗ Prix initial = 80€ + 20% = 96€ (faux)
✓ Prix initial = 80€ ÷ 0,80 = 100€
🪤
Intérêts composés ≠ intérêts simples
1000€ à 5% sur 2 ans : avec intérêts simples = 100€. Avec intérêts composés = 102,50€. Le concours précise généralement lequel utiliser.
✓ Simples : 1000 × 5% × 2 = 100€ · Composés : 1000 × (1,05)² − 1000 = 102,50€
🪤
Arbres plantés le long d'un chemin — +1 oublié
Sur 60m avec un arbre tous les 3m (en comptant les deux extrémités) : 60÷3 = 20 intervalles, mais 21 arbres !
✗ 60 ÷ 3 = 20 arbres
✓ 60 ÷ 3 + 1 = 21 arbres
🪤
Priorité des opérations — PEMDAS oublié
L'ordre est : Parenthèses → Exposants → Multiplication/Division → Addition/Soustraction.
✗ 4 − 5 × 8 + 3 = (4−5) × (8+3) = −11 (faux)
✓ 4 − (5×8) + 3 = 4 − 40 + 3 = −33
🧠 Raisonnement
🪤
Affirmer le conséquent — erreur logique classique
Ce n'est pas parce que la conclusion est vraie que la prémisse est vraie. Piège très fréquent dans les questions de syllogisme.
✗ Tous les chiens aboient. Médor aboie. Donc Médor est un chien. (FAUX logiquement)
✓ Médor aboie mais pourrait être un autre animal.
🪤
"Plus de 3 jours" ≠ "3 jours ou plus"
Dans les questions de règlement et de texte de loi, la rigueur du langage juridique est testée. "Plus de 3" = strictement supérieur à 3 (donc 4 minimum).
✓ "Plus de 3 jours" → la règle s'applique à partir de 4 jours, pas 3.
💡
Stratégie examen : ne pas se précipiter sur la 1ère réponse plausible
Les QCM de raisonnement comportent souvent une réponse "évidente" qui est un piège. Lire toutes les propositions avant de choisir.
✓ Lire les 4 options en entier, éliminer les mauvaises, puis choisir.
📋 Stratégie générale
⏱️
Gestion du temps : 1h30 pour 54 questions
Soit 1 minute 40 secondes par question en moyenne. Les questions d'orthographe sont souvent rapides (30s), celles de calcul peuvent prendre 3-4 min. Compensez.
✓ Conseil : ne pas bloquer plus de 3 min sur une question. Passer et revenir.
❌
Barème : une mauvaise réponse coûte 0,25 point
Ne répondez pas au hasard. Une omission vaut 0. Une mauvaise réponse retire 0,25 point. Si vous hésitez entre 2 propositions, répondre vaut quand même le risque. Si vous n'avez aucune idée parmi 4 options → passer.
✓ Répondre si vous avez éliminé 2 options. Passer si vous êtes totalement dans le noir.
🚨
Seuil éliminatoire : 5/20
Toute note inférieure à 5/20 est éliminatoire, quelle que soit votre performance aux autres épreuves. Ce seuil est strict et non négociable.
✓ Objectif minimum : 14 bonnes réponses sur 54 (≈ 26% brut) pour dépasser 5/20 après pénalités.
